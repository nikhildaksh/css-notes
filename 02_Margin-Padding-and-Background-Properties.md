# Lecture 2 — Margin, Padding & Background Properties

## What is Margin?
Margin is the **outer space** around an element.

```css
/* Individual sides */
margin-top: 10px;
margin-right: 20px;
margin-bottom: 10px;
margin-left: 20px;

/* Shorthand */
margin: 20px 10px;              /* top-bottom  left-right */
margin: 10px 20px 30px 40px;   /* top right bottom left */
```

---

## What is Padding?

Padding is the **inner space** inside an element.

```css
/* Individual sides */
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

/* Shorthand */
padding: 20px 10px;
padding: 10px 20px 30px 40px;
```

---

## Background Properties

```css
background-color: lightblue;
background-image: url("photo.jpg");
background-repeat: no-repeat;
background-size: cover;
```
